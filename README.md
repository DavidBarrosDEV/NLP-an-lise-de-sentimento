# Análise de Sentimentos em Críticas de Filmes com NLTK

Este projeto utiliza o **NLTK (Natural Language Toolkit)**, uma das principais bibliotecas de Processamento de Linguagem Natural em Python, para realizar análise de sentimentos em críticas de filmes.

## 📚 Objetivo

O objetivo principal é aplicar técnicas de NLP para classificar críticas de filmes como positivas ou negativas, utilizando ferramentas como tokenização, remoção de stopwords e classificação com Naive Bayes.

## 🧰 Tecnologias Utilizadas

- Python
- Jupyter Notebook
- NLTK
- Pandas
- Scikit-learn

## 📁 Estrutura do Projeto

- **`nlpfilmesct.ipynb`**: Notebook principal contendo a implementação da análise de sentimentos.
- **`otimiz.ipynb`**: Notebook focado na otimização do modelo de classificação.
